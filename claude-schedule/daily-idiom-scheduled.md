## Task

매일 의미 있는 사자성어 하나를 선정하고, 뜻과 유래, 예문, 오늘의 한마디를 포함한 풍성한 콘텐츠를 생성하여 `~/claude/daily-idiom/` 폴더에 텍스트 파일로 저장합니다.

## Steps

1. 오늘 날짜(YYYY-MM-DD, 요일) 확인
2. 최근 7일간 `~/claude/daily-idiom/` 폴더에 저장된 파일을 확인하여 이미 다룬 사자성어는 제외
3. 오늘의 사자성어 하나를 선정 (계절, 요일, 시의성 고려)
4. 아래 "Output Format"에 맞춰 콘텐츠 구성
5. `~/claude/daily-idiom/YYYY-MM-DD-오늘의-사자성어.txt` 파일로 저장
6. 파일이 이미 존재하면 덮어쓰지 말고 `-v2.txt` 접미사 추가

## Output Format

파일명: `YYYY-MM-DD-오늘의-사자성어.txt`
인코딩: UTF-8
구분선은 `═` 와 `─` 를 사용하며 꽃말 포맷과 통일성 유지.

```
═══════════════════════════════════════
      오늘의 사자성어 · YYYY-MM-DD (요일)
═══════════════════════════════════════

📜 오늘의 사자성어: 한글 (漢字)
   음훈: 각 한자의 음과 훈
   분류: 교훈/처세/학문/인간관계 등

───────────────────────────────────────
💡 뜻
───────────────────────────────────────
  • 직역
  • 의역 / 현대적 해석

───────────────────────────────────────
📖 유래
───────────────────────────────────────
출전(고전 서적, 역사적 일화 등)과 배경 이야기를
3~5문장으로 풀어서 소개.

───────────────────────────────────────
✍️ 예문
───────────────────────────────────────
  1. 일상에서 쓸 수 있는 예문
  2. 비즈니스/학업 상황에서의 예문

🔗 비슷한 사자성어: XXXX, YYYY
🔀 반대 의미: ZZZZ (있다면)

───────────────────────────────────────
✨ 오늘의 한마디
───────────────────────────────────────
"사자성어를 관통하는 짧은 문장 한 줄."

오늘 하루, 이 사자성어를 어떻게 적용해볼 수 있을지
2~3문장의 따뜻한 코멘트로 마무리.

═══════════════════════════════════════
```

## Selection Guidelines

- 너무 어렵거나 낯선 사자성어보다는 일상에 녹아들 수 있는 것 우선
- 계절(봄/여름/가을/겨울), 요일(월~금은 근면/목표, 주말은 여유/관계) 특성 반영
- 공휴일·기념일이 있다면 관련된 사자성어 선정
- 교훈·처세·학문·인간관계·자연·시간 등 주제를 돌아가며 다양성 확보

## Error Handling

- 폴더가 없으면 `~/claude/daily-idiom/` 자동 생성
- 동일 날짜 파일이 이미 있으면 파일명 뒤에 `-v2`, `-v3` 추가
- 최근 7일 파일 조회 실패 시 경고 로그만 남기고 진행
