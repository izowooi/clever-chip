## Task

매일 계절과 시의성에 어울리는 꽃 하나를 선정하고, 꽃말·유래·이야기·오늘의 한마디를 포함한 따뜻한 콘텐츠를 생성하여 `~/claude/daily-flower/` 폴더에 텍스트 파일로 저장합니다.

## Steps

1. 오늘 날짜(YYYY-MM-DD, 요일) 확인
2. 최근 14일간 `~/claude/daily-flower/` 폴더에 저장된 파일을 확인하여 이미 다룬 꽃은 제외
3. 오늘의 꽃 하나를 선정 (현재 계절에 실제로 피는 꽃 우선, 기념일/절기 반영)
4. 아래 "Output Format"에 맞춰 콘텐츠 구성
5. `~/claude/daily-flower/YYYY-MM-DD-오늘의-꽃말.txt` 파일로 저장
6. 파일이 이미 존재하면 덮어쓰지 말고 `-v2.txt` 접미사 추가

## Output Format

파일명: `YYYY-MM-DD-오늘의-꽃말.txt`
인코딩: UTF-8
구분선은 `═` 와 `─` 를 사용.

```
═══════════════════════════════════════
        오늘의 꽃말 · YYYY-MM-DD (요일)
═══════════════════════════════════════

🌸 오늘의 꽃: 한글명 (영문명)
   학명: Scientific name
   영문명: Common name
   과: 식물학적 분류 (XXX과)

───────────────────────────────────────
💬 꽃말
───────────────────────────────────────
  • 대표 꽃말 1
  • 대표 꽃말 2
  • 대표 꽃말 3

색깔별 꽃말: (해당되는 경우만)
  - 빨간색: ...
  - 흰색: ...
  - 분홍색: ...

───────────────────────────────────────
🌿 꽃 이야기
───────────────────────────────────────
원산지, 개화 시기, 특징, 신화/전설/문화적 의미를
4~6문장으로 자연스럽게 풀어 소개.

───────────────────────────────────────
✨ 오늘의 한마디
───────────────────────────────────────
"꽃말의 정서를 담은 짧은 시구 한두 줄."

계절감과 꽃이 전하는 메시지를 연결한
2~3문장의 따뜻한 마무리 멘트.

═══════════════════════════════════════
```

## Selection Guidelines

- 현재 계절에 실제로 피는 꽃 우선 (봄: 벚꽃·라일락·튤립, 여름: 해바라기·수국, 가을: 코스모스·국화, 겨울: 동백·수선화 등)
- 너무 유명한 꽃(장미·튤립)만 반복하지 말고 덜 알려진 꽃도 골고루
- 기념일·절기(입춘·경칩·발렌타인데이·어버이날 등)와 어울리는 꽃 우선
- 색깔별 꽃말이 있는 꽃은 색상 구분 표기

## Error Handling

- 폴더가 없으면 `~/claude/daily-flower/` 자동 생성
- 동일 날짜 파일이 이미 있으면 파일명 뒤에 `-v2`, `-v3` 추가
- 최근 14일 파일 조회 실패 시 경고 로그만 남기고 진행
