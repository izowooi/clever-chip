# L1 워크플로우

L1은 사용자 전체 개발 철학·안전 규칙을 담는 최상위 AGENTS.md. 1회 작성, 거의 변하지 않음.

## Analyst 역할 (최소)

L1에서 Analyst는 코드 분석 부담이 거의 없다. 다음만 수행:
- `target_path` 자식 디렉토리에서 git 저장소 enumerate (L1 본문에 "내 저장소는 ~ 아래에 있다" 명시용)
- 부모 AGENTS.md 없음 확인 (L1은 최상위라 부모 없어야 정상)
- 시스템 정보 (OS, 셸) 확인 — 사용자 CLAUDE.md에 이미 있으면 skip

## 인터뷰 질문 (10개, 순서대로)

각 질문은 "추천 답변 + 출처 + 왜 + 선택지 A/B/C" 형식. 출처는 대부분 **가이드** (가이드 105~210행 권장 규칙).

### Q1. AI의 기본 자율성 수준

**추천 (균형 모드):**
```text
AI는 요청받은 작업 범위 안에서 자율적으로 수정·테스트·커밋까지 진행할 수 있다.
push, force push, 대량 삭제, secret 수정, 유료 리소스 생성, 운영 배포, macOS 시스템 설정 변경은 사용자 승인 후 진행한다.
```
**출처:** 가이드 1187~1227행
**선택지:** A. 보수적 / B. 균형(추천) / C. 자동화 우선

### Q2. Git 기본 정책

**추천:**
```text
- 작업 전후 git status 확인
- 의도한 파일만 staging
- 커밋 메시지는 짧고 명확한 한글, 기술 용어는 영문
- 문서만 수정한 경우 테스트/빌드 생략 사유를 응답에 남김
- push는 사용자 승인 후
```
**출처:** 가이드 158~165행
**선택지 (multiSelect 가능):** A. 위 권장값 그대로 / B. 자동 push까지 허용 / C. 모든 git 명령에 승인 필요

### Q3. TDD 강제 수준

**추천:** "불확실한 요구사항은 합리적으로 추론하되, 위험하거나 되돌리기 어려운 결정은 먼저 확인"

**추천 (체크리스트):** push / force push / 대량 삭제 / `rm -rf` / secret 출력·수정 / `.env` 덮어쓰기 / 유료 리소스 생성 / 운영 배포 / macOS 시스템 설정 변경 / 외부 서비스 데이터 업로드 — 모두 승인 필수
