## 작업 규칙

- 기능 변경 시 가능한 한 실패 테스트를 먼저 추가한다.
- 외부 API 호출 코드는 mock 또는 dry-run으로 검증한다.
- secret, token, credential은 출력하지 않는다.
- `.env`는 직접 수정하지 않는다.
- 실제 운영 job, 배포, 결제, 외부 전송은 사용자 승인 후 진행한다.
