## 작업 범위

- 요청받은 범위 안에서만 수정한다.
- 관련 없는 파일, 폴더, 설정은 임의로 변경하지 않는다.
- 이미 존재하는 사용자 변경사항을 되돌리지 않는다.
- 작업 중 발견한 별도 이슈는 제안만 하고, 요청 범위 밖이면 임의로 수정하지 않는다.

## 작업 전 확인 순서

작업 시작 전 아래 파일이 존재하면 먼저 읽는다.

1. 현재 경로와 상위 경로의 `AGENTS.md`
2. 프로젝트 루트의 `CLAUDE.md`
3. 프로젝트 루트의 `README.md`
4. 프로젝트 루트의 package/config 파일
5. CI/CD 관련 파일

상위 지침과 하위 지침이 충돌하면 더 구체적인 하위 지침을 우선한다.
